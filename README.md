#Portal Parkir Otomatis
Sistem Portal Parkir Otomatis merupakan aplikasi berbasis Python yang dirancang untuk mensimulasikan sistem manajemen parkir modern secara otomatis melalui terminal/CLI (Command Line Interface). Sistem ini mampu mengelola kendaraan masuk dan keluar, menentukan slot parkir secara otomatis, menghitung tarif parkir berdasarkan durasi, serta menyediakan dashboard monitoring kendaraan aktif. Project ini dibuat untuk mengimplementasikan konsep Object-Oriented Programming (OOP), manajemen data, algoritma pencarian slot parkir, serta simulasi sistem parkir digital menggunakan bahasa pemrograman Python.

## Fitur Utama
- Sistem tiket digital
- Slot parkir otomatis
- Dashboard monitoring
- Perhitungan tarif parkir
- Pencarian kendaraan
- Simulasi parkir real-time

## Pembelajaran yang Didapat
- Implementasi OOP pada Python
- Pengelolaan data menggunakan dictionary
- Simulasi sistem otomatisasi
- Manajemen slot parkir menggunakan matrix
- Pengolahan waktu dan perhitungan tarif
- sistem login admin
